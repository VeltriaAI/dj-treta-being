# NS-002 — Typed internal event seam (framework-independent state stream)

**Status:** DEFINED — 2026-07-05
**Vision link:** VISION.md → Phase 0 — Foundation. The seam insulates every consumer (TUI, thinking.log, notebook, billing, future web UI) from google-adk types; prerequisite for both the web UI (Phase 1) and the Pydantic beachhead (Phase 3).

## Scope

Introduce typed internal event dataclasses and route existing broadcasts through
them, keeping the on-the-wire JSON contract **byte-stable**:

1. `agent/events.py` (new): `ThinkEvent`, `CallEvent`, `BillingEvent` dataclasses
   + a minimal `AgentInvoker` protocol type (structural, no behavior change).
2. Route the existing `ws_broadcast("thinking"/"call"/"billing", ...)` emissions,
   `thinking.log` writes, and notebook taps through constructors of these types
   (each has a `.to_wire()` producing exactly today's dict shape).
3. A contract test asserting `.to_wire()` output is byte-identical (key set +
   value types) to the current hand-built dicts for representative samples.

## Out of Scope

- Any change to the /ws/state wire format, TUI, or relay frames
- Any ADK/Pydantic change; any new endpoints
- Per-agent model map (NS-003); web UI (NS-004+)

## Acceptance Criteria (≤5)

1. All thinking/call/billing broadcasts constructed via the new event types —
   grep shows no remaining hand-built dicts at those emit sites.
2. Wire contract test passes: `.to_wire()` output identical (keys + types) to
   pre-change captures for all three event kinds.
3. Live check: TUI (or ws client) renders thinking/billing exactly as before on
   a running daemon; thinking.log format unchanged (diff a sample window).
4. Full unit suite: no new failures vs baseline (1 pre-existing).
5. Single revertable PR-sized commit on the branch.
