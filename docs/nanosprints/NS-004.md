## Scope

1. `web/` directory: Vite + Svelte + TypeScript SPA, fully self-contained
   (no CDN imports — assessment constraint), building to a static bundle.
2. WS client module: connects to `ws://<host>:7779/ws/state`, handles the
   existing envelope (state/billing/thinking ring-replay/log/mixxx_status/
   mixxx_live), exponential-backoff reconnect, staleness flag.
3. First render surface: connection status, raw-ish live panels (now-playing/
   decks skeleton, thinking stream, billing counter) — structure over polish;
   visual design deepens in NS-005.
4. `web/mock/` replay harness: a tiny dev server replaying captured frames so
   the UI develops + demos with NO daemon.
5. Identity: DJ Treta / treta.life aesthetic (her own brand, dark, live-set
   energy) — NOT the Ecme/InfraX template (that rule is for InfraX business
   UIs; deviation noted for Manish).

## Acceptance Criteria (≤5)

1. `npm run build` produces a static bundle with zero external network deps
   (grep dist for http(s) CDN refs = none).
2. Against the mock replay server, the UI renders: connection state, thinking
   stream (ring replay on connect), billing figure, deck/now-playing skeleton.
3. WS drop → reconnect with backoff; last-known frame stays visible with a
   staleness indicator (mock server kill/restart test).
4. TypeScript strict; `npm run check` (svelte-check) clean.
5. Single revertable commit; nothing outside `web/` + docs touched.
