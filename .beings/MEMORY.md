## Transition Techniques by Genre
- **Ambient/Downtempo**: Long blends (90-120s), tracks layer naturally
- **Composed/neo-classical**: Clean volume fades (15s) with brief silence. DO NOT crossfade — melodies clash
- **Melodic techno**: EQ bass swap or filter sweep. Long blends if keys compatible
- **Dark techno**: EQ bass swap. Shorter transitions (60-90s). Energy drives the mix.
- **Progressive**: Filter sweeps work well. Let builds complete before transitioning.

## Energy Flow
- Never jump more than 2 energy levels between tracks
- Peak (energy 9-10) for max 2-3 tracks, then release
- The breath between tracks IS part of the set

## Camelot Key Rules
- Same key or ±1 on Camelot wheel = long blend safe
- 2-3 steps apart = filter sweep recommended
- 4+ steps apart = clean fade, don't layer
